  <action>
Run Lighthouse audit on the gallery test page and fix any issues found.

**Step 1: Build and start production server**
```bash
npm run build && npm run start
```

**Step 2: Run Lighthouse CLI audit**
```bash
npx lighthouse http://localhost:3000/gallery-test --only-categories=performance --output=json --output-path=./lighthouse-gallery.json --chrome-flags="--headless" --preset=desktop
```
Then run mobile (default):
```bash
npx lighthouse http://localhost:3000/gallery-test --only-categories=performance --output=json --output-path=./lighthouse-gallery-mobile.json --chrome-flags="--headless"
```

**Step 3: Analyze results**
Check the JSON output for:
- Performance score (target: 100, minimum acceptable: 90)
- LCP (target: under 2.5s)
- CLS (target: under 0.1)
- TBT (Total Blocking Time -- should be near 0 with Server Components)
- Any flagged issues: unused CSS, render-blocking resources, improperly sized images

**Step 4: Fix any issues found**
Common fixes based on research anti-patterns:
- If LCP is high: Ensure no gallery images have `priority` prop (only hero images should). Check that the first visible content is not a large unoptimized image. Consider adding a page heading above the gallery so LCP is text, not an image.
- If CLS is high: Ensure all images have explicit width/height from metadata (or aspect-ratio on container for grid mode). Check that no fonts cause layout shift (Playfair Display and Lato should already be in next/font from Phase 1).
- If unused CSS flagged: Verify lightbox CSS is NOT in the initial bundle (should only be in dynamically imported GalleryLightbox).
- If performance score below 95: Check for any client-side JS that shouldn't be there. The gallery grid should be Server Component rendered. Only GalleryClient should be client-side, and it should be minimal (just state management).

**Step 5: Verify tap targets**
Check that all interactive elements in the gallery meet 44x44px minimum:
- Gallery image click targets (the button wrapping each image -- should be at least 44x44 since images are larger)
- Lightbox close button (YARL default should be sufficient, but verify)
- Lightbox navigation arrows (YARL default should be sufficient, but verify)
- If any are undersized, add min-h-11 min-w-11 (44px) to the element

**Step 6: Re-run Lighthouse after fixes**
If any changes were made, rebuild and re-audit to confirm improvements.

Clean up lighthouse JSON files after verification (do not commit them):
```bash
rm -f lighthouse-gallery.json lighthouse-gallery-mobile.json
```
