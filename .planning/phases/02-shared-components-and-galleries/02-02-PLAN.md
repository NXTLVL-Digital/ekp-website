**Section** (src/components/shared/Section.tsx):
- Props: children, className (optional string), background ('white' | 'muted', default 'white'), id (optional string)
- Renders `<section>` with vertical padding (py-16 md:py-24 or similar -- use generous spacing for premium feel), conditional background color (bg-background for white, bg-muted for muted), and inner `<div>` with max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
- Passes through className and id
- This is the foundational wrapper every page section will use

**PricingCard** (src/components/shared/PricingCard.tsx):
- Props: name (string), startingAt (number), description (string), features (string[]), ctaHref (string, default '/contact'), ctaLabel (string, default 'Inquire for Detailed Pricing'), highlight (boolean, default false)
- Renders a card with: package name (font-heading text-2xl), description (text-muted-foreground), "Starting At" label (text-sm text-muted-foreground) above price (font-heading text-3xl formatted as "$X"), features list with gold checkmark icons, and CTA button
- Highlight variant: border-brand-gold with bg-brand-gold/5 background. Normal: border-border bg-white
- CTA button: Use Next.js Link component, styled as gold button (bg-brand-gold text-white hover:bg-brand-gold-dark), min-h-11 for 44x44px tap target, centered text, rounded
- Scarcity cues should be attention-grabbing but not pushy (per user decision) -- the gold accent is warm, not aggressive
- Card should feel premium: generous padding (p-6 md:p-8), rounded-lg, subtle shadow on hover (shadow-md transition-shadow)

**ScarcityCue** (src/components/shared/ScarcityCue.tsx):
- Props: message (string), isActive (boolean)
- Returns null when isActive is false
- When active: renders a warm, attention-getting banner with gold accent (border-brand-gold/30 bg-brand-gold/5), pulsing gold dot (animate-pulse), and the message text
- Styling: rounded-lg, centered text, text-sm font-medium
- The pulsing dot uses a small span with rounded-full bg-brand-gold animate-pulse
- Do NOT make this look like an error or warning -- it should feel like a gentle, warm nudge ("Only 5 Spring slots remaining" not "WARNING: LIMITED AVAILABILITY")

**Storyboard** (src/components/shared/Storyboard.tsx):
- Props: steps array of { number: number, title: string, description: string, image?: SanityImage asset shape (optional) }
- Renders a visual timeline showing the session experience journey (e.g., "1. Planning Call" -> "2. Wardrobe Consult" -> "3. Your Session" -> "4. Reveal & Order")
- Layout: On mobile, vertical stack with numbered circles connected by a line. On desktop, horizontal flow or alternating layout.
- Each step: a numbered circle (bg-brand-gold text-white rounded-full w-10 h-10 flex items-center justify-center font-heading text-lg), title (font-heading text-lg), description (text-muted-foreground text-sm), optional image rendered with SanityImage
- Connecting line between steps: a thin gold line (bg-brand-gold/30) connecting the numbered circles
- The design should feel editorial and premium -- this is a key conversion element showing the "experience" of working with Emily
- Import SanityImage only if the step image rendering needs it; otherwise use a conditional check

**AnswerBlock** (src/components/shared/AnswerBlock.tsx):
- Props: items array of { question: string, answer: string }, id (optional string for anchor links)
- Uses native HTML `<details>` and `<summary>` elements for zero-JS accordion behavior
- Each item: `<details>` with `<summary>` containing the question (font-heading text-lg cursor-pointer) and the answer in a `<div>` below (text-muted-foreground, padded)
- Style the disclosure triangle: use `list-none` on summary and add a custom chevron (rotate on open using `[open] > summary` CSS selector or Tailwind's `group-open` with a `<details>` as group)
- Separator between items: border-b border-border
- The accordion is SEO-friendly (Google reads content in both open and closed states)
- This component is for FAQ sections. The AEO "answer blocks" on city pages (Phase 5) are a DIFFERENT use case (always visible, not collapsed) -- they will be a separate component or variant later
- Accessible by default: details/summary supports keyboard operation and screen readers natively

**JsonLd** (src/components/shared/JsonLd.tsx):
- Generic typed component using schema-dts for compile-time type safety
- Import types: `import type { Thing, WithContext } from 'schema-dts'`
- Props: data of type WithContext<T> where T extends Thing
- Renders a `<script type="application/ld+json">` tag with dangerouslySetInnerHTML
- CRITICAL XSS prevention: Replace `<` with `\\u003c` in the JSON string to prevent script injection: `JSON.stringify(data).replace(/</g, '\\u003c')`
- This is the Next.js App Router recommended pattern (NOT react-schemaorg)
- Zero runtime cost -- just a script tag rendered server-side
