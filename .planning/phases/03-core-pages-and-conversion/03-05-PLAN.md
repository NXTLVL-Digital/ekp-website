    Ensure each page exports complete `metadata` with:
    ```typescript

      openGraph: {

        description: 'Same or similar to meta description',
        url: 'https://emilykathryn.com/page-slug',

        description: 'Same description',
        images: ['/og/page-slug.jpg'],
      },
    }
    ```
