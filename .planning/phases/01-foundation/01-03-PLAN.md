    **File 3: src/components/layout/HeaderClient.tsx — Client Component with scroll-aware behavior**

    `'use client'` component implementing:

    1. **Scroll-aware sticky behavior:** Uses `useState` + `useEffect` with passive scroll listener. Header is `fixed top-0` with `z-50`. On scroll DOWN past 80px threshold, applies `transform: translateY(-100%)` to hide. On scroll UP (or at top of page), reveals with `translate-y-0`. Use `transition-transform duration-300` for smooth animation.

    2. **Desktop navigation (lg: breakpoint and up):**
       - Logo text link (`siteConfig.name`) on the left, styled with `font-heading text-lg tracking-wide`
       - Navigation links in center/right area, each with `min-h-11 flex items-center` for 44px tap targets (FOUND-06)
       - Text: `text-sm font-body tracking-wide text-foreground/80 hover:text-foreground transition-colors`
       - CTA button on far right: `bg-brand-gold text-white text-sm font-body tracking-wide rounded hover:bg-brand-gold-dark transition-colors min-h-11 px-5 py-2.5`

    3. **Mobile hamburger button (below lg: breakpoint):**
       - Hidden on desktop (`lg:hidden`)
       - Minimum 44x44px: `min-h-11 min-w-11 flex items-center justify-center`
       - Renders a hamburger icon (three horizontal lines) as SVG or spans
       - `aria-label="Open menu"`
       - On click: opens MobileNav overlay

    4. **Header background:** `bg-white/95 backdrop-blur-sm border-b border-border` for subtle translucency

    5. **State management:** `isMenuOpen` state passed to MobileNav. When menu is open, hamburger transforms to X (close icon).

    Props interface:
    ```typescript
    interface HeaderClientProps {
      navigation: ReadonlyArray<{ readonly label: string; readonly href: string }>
      cta: { readonly label: string; readonly href: string }
      logoText: string
    }
    ```

    **File 4: src/components/layout/MobileNav.tsx — Full-screen overlay menu**

    `'use client'` component implementing a full-screen overlay menu:

    1. **Overlay container:** Fixed position covering the full viewport (`fixed inset-0 z-40`). White background. CSS transition for entry/exit animation (fade or slide-down).

    2. **Close button:** Top-right position, 44x44px minimum, renders X icon, `aria-label="Close menu"`.

    3. **Navigation links:** Large, centered text. Each link: `text-2xl font-heading tracking-wide` with generous vertical padding for easy tapping. Each link has `min-h-11` (44px minimum tap target per FOUND-06). Use `<Link>` from `next/link`.

    4. **CTA button at bottom:** Full-width or prominent placement at the bottom of the nav list. Same gold styling as desktop CTA but larger: `bg-brand-gold text-white text-lg font-body py-4 px-8 rounded`.

    5. **Accessibility:**
       - Focus trap: When overlay opens, focus moves to the first nav link. Tab cycles through nav items only (not background content).
       - ESC key closes the menu
       - `aria-modal="true"` and `role="dialog"` on the overlay
       - When a link is clicked, the menu closes automatically

    6. **Body scroll lock:** When overlay is open, set `document.body.style.overflow = 'hidden'` to prevent background scrolling. Remove on close.

    Props:
    ```typescript
    interface MobileNavProps {
      navigation: ReadonlyArray<{ readonly label: string; readonly href: string }>
      cta: { readonly label: string; readonly href: string }
      isOpen: boolean
      onClose: () => void
    }
    ```
