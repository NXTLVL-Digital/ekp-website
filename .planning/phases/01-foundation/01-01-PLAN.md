  <name>Task 1a: Scaffold Next.js project with Tailwind v4 brand theme, fonts, and route groups</name>
  <files>
    package.json

    tsconfig.json
    postcss.config.mjs
    src/app/globals.css

    src/app/(site)/page.tsx
    src/app/(site)/not-found.tsx
    src/fonts/ (placeholder for Acrom woff2 files)
    .gitignore
  </files>
  <action>
    **Step 1: Create Next.js project**
    Run `npx create-next-app@15 . --typescript --tailwind --app --src-dir --import-alias "@/*"` in the project root. If the directory already has files, use a temp directory and move files.

    **Step 2: Install core dependencies**
    ```bash
    npm install @vercel/analytics @vercel/speed-insights schema-dts
    npm install -D @types/node prettier prettier-plugin-tailwindcss
    ```

    **Step 3: Configure next.config.ts**
    Set `images.remotePatterns` for `cdn.sanity.io`. Enable `compiler.styledComponents: true` (for Sanity Studio styled-components peer dep).

    **Step 4: Configure Tailwind v4 globals.css**
    Replace default globals.css with `@import "tailwindcss"` + `@theme` block containing:
    - Brand colors: `--color-brand-gold: #c2a36c`, `--color-brand-gold-dark: #a88c55`, `--color-brand-rose: #dcb6ad`, `--color-brand-sage: #b3d4cd`, `--color-brand-gray: #d6d4d4`
    - Core palette: `--color-background: #ffffff`, `--color-foreground: #1a1a1a`, `--color-muted: #f5f5f5`, `--color-muted-foreground: #737373`, `--color-border: #e5e5e5`
    - Typography: `--font-heading: var(--font-cormorant), ui-serif, Georgia, serif`, `--font-body: var(--font-acrom), ui-sans-serif, system-ui, sans-serif`
    - Spacing: `--spacing-section: 5rem`, `--spacing-section-sm: 3rem`

    **Step 5: Font configuration**
    In `src/app/(site)/layout.tsx`:
    - Import Cormorant_Garamond from `next/font/google` with weights ['300','400','500','600','700'], variable `--font-cormorant`, display `swap`
    - Import Acrom via `next/font/local` with variable `--font-acrom`, display `swap`. For initial scaffolding, if Acrom .woff2 files are not yet available, create a `src/fonts/` directory with a README noting the font files are needed. Use a system sans-serif fallback in the CSS variable temporarily. When Acrom files are provided, the localFont config is ready to plug them in.
    - Apply both font CSS variables to the wrapper div: `className={`${cormorant.variable} ${acrom.variable} font-body`}`

    **Step 6: Root layout (app/layout.tsx)**
    Minimal: `<html lang="en">` + `<body>` + `{children}`. No site UI. This is the shared root for both (site) and (studio) route groups.

    **Step 7: Site layout (app/(site)/layout.tsx)**
    Include font variables, `<Analytics />` from `@vercel/analytics/next`, `<SpeedInsights />` from `@vercel/speed-insights/next`. Include stub `<header>` and `<footer>` elements with minimal content (logo text, copyright) -- these will be replaced by full components in Plan 01-03. Wrap children in `<main>`.

    **Step 8: Placeholder homepage (app/(site)/page.tsx)**
    Simple page with `<h1>Emily Kathryn Photography</h1>` using `font-heading` class, a `<p>` with body text using `font-body`, and a test element using `bg-brand-gold text-white` to verify theme tokens. Export metadata with title and description. The page MUST render with a white dominant background. Brand-gold should appear only on the small accent test element (less than 5% of page area). No ornate or decorative fonts -- Cormorant Garamond is used for the heading only, body text uses the sans-serif stack.

    **Step 9: Custom 404 (app/(site)/not-found.tsx)**
    Simple not-found page with heading and link back to homepage.

    **IMPORTANT NOTES:**
    - Do NOT use `framer-motion` -- use `motion` package if animation is needed (rebranded)
    - Do NOT use `images.domains` in next.config -- use `images.remotePatterns` (domains is deprecated)
    - The `postcss.config.mjs` should use `@tailwindcss/postcss` plugin (Tailwind v4 requirement)
  </action>
  <verify>
    1. Run `npm run dev` and confirm http://localhost:3000 loads the placeholder homepage without errors
    2. Confirm heading text renders in Cormorant Garamond (or serif fallback), body in sans-serif
    3. Confirm the gold-colored test element renders with #c2a36c background
    4. Confirm the page background is white — no large colored blocks or ornate patterns
    5. Run `npm run build` and confirm no build errors
  </verify>
  <done>
    Next.js app scaffolded with Tailwind v4 brand theme, Cormorant Garamond heading font, route groups for site vs studio, placeholder homepage with white dominant background and gold accent-only usage, and custom 404 page. Build succeeds without errors.
  </done>

    ```bash
    npm install sanity@4 next-sanity@11 @sanity/client @sanity/image-url @sanity/vision styled-components
    ```

    **Step 2: Studio page (app/(studio)/studio/[[...tool]]/page.tsx)**
    `'use client'` component importing `NextStudio` from `next-sanity/studio` and `config` from `@/sanity/sanity.config`. Render `<NextStudio config={config} />`. Export metadata with `title: 'Emily Kathryn Photography | Studio'`.

    **Step 3: Sanity env.ts**
    Export `apiVersion` (default `'2025-03-04'`), `dataset`, `projectId` using the `assertValue` pattern from research. Read from `NEXT_PUBLIC_SANITY_*` env vars.

    **Step 4: Sanity client.ts**
    Create client with `createClient` from `next-sanity`, importing projectId/dataset/apiVersion from env.ts. Set `useCdn: true`.

    **Step 5: Sanity live.ts**
    Import `defineLive` from `next-sanity/live` (NOT root import -- v11 subpath). Configure with client. Export `{ sanityFetch, SanityLive }` from `defineLive`.

    **Step 6: Sanity schemas**
    Create `siteSettings.ts` schema with fields: businessName (required string), tagline (string), phone (required string), email (required string + email validation), address (object: street/city/state/zip), socialLinks (object: instagram/facebook/tiktok URLs). Create `schemas/index.ts` exporting the array `[siteSettings]`.

    **Step 7: Sanity config (sanity.config.ts)**
    Use `defineConfig` from `sanity`. Set name, title ('Emily Kathryn Photography'), projectId/dataset from env. Include `structureTool()` and `visionTool()` plugins. Register schemas from schemas/index.

    **Step 8: Environment files**
    Create `.env.local` with placeholder values:
    ```
    NEXT_PUBLIC_SANITY_PROJECT_ID=""
    NEXT_PUBLIC_SANITY_DATASET="production"
    NEXT_PUBLIC_SANITY_API_VERSION="2025-03-04"
    SANITY_REVALIDATE_SECRET=""
    ```
    Create `.env.example` with same keys (no values). Ensure `.gitignore` includes `.env.local`.

    **Step 9: Deploy to Vercel**
    Run `npx vercel --yes` to connect the project and create the initial deployment. This creates the Vercel project and deploys the current state. The deployment URL will be printed to the terminal. If Vercel CLI is not installed, run `npm install -g vercel` first.

    **IMPORTANT NOTES:**
    - Do NOT import `defineLive` from `next-sanity` root -- must use `next-sanity/live` subpath (v11 change)
    - Do NOT put `<SanityLive>` in the (studio) layout -- only in (site) layout
  </action>
